### B. 题库分类（`docs/questions.js`）

新增 6 个分类，命名对齐现有「广立微 / …」：

| 分类 | 覆盖重点 | 建议题量 |
|------|----------|----------|
| `恒生 / 岗位与业务` | 全内存交易、经纪业务、证券场景认知 | 5–7 |
| `恒生 / C++与内存` | C/C++、内存管理、RAII、性能相关 | 6–8 |
| `恒生 / Linux与调试` | 常用命令、gdb、服务端基础 | 5–7 |
| `恒生 / 并发与进程` | 多线程/多进程、同步、常见坑 | 5–7 |
| `恒生 / 数据库基础` | 事务 ACID、索引、一致性直觉 | 4–6 |
| `恒生 / 系统设计` | 模块设计、排查、架构口述 | 4–6 |

合计约 **30–40 题**。题目 id 前缀统一：`hs-`。

题目质量约定（与现有题库一致）：

- `answerPoints` ≥ 3
- 口述友好，强调区别、原理、场景与工程取舍
- 高频题 `highFrequency: true` 优先覆盖 JD 必考面
- keywords 含「恒生」及技能关键词，便于搜索
