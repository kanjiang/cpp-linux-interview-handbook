一句话定位

内存做交易，磁盘做兜底。热路径无随机 IO；WAL + 快照保证可恢复；对账保证最终正确。

硬约束：低延迟 · 无 GC 停顿 · 订单零丢失 · 状态强一致。

必背 1 · 四层架构

  1. 内存数据结构（资金/持仓/委托）
  2. 状态机 + 并发控制
  3. WAL + Snapshot 持久化
  4. 故障恢复 + 三方对账

必背 2 · 订单五步

  1. 网关接入校验 / 前置风控
  2. 内存查资券 → 冻结 → 建委托（可撮合）
  3. 更新内存后写 WAL（同步/异步按风险）
  4. 宕机：快照 + 重放 WAL 重建
  5. 对账：内存 · WAL · 交易所回报

必背 3 · 经典三问

为什么快？

  • 热数据在内存，避 DB 随机 IO
  • 内存池预分配，热路径少 malloc
  • 撮合单线程减锁；TCP_NODELAY

一致性？

  • WAL 留痕 + 快照基线
  • 三方对账
  • 状态机约束冻结/解冻

宕机丢单？

  • 成功应答前保证日志落盘等级达标
  • 快照 + WAL 重放还原已受理单
  • 已报交易所：恢复后主动查终态补齐

必背 4 · C++ 热路径口诀

  • Order/Hold：拷贝 = delete，能移动就移动，移动尽量 noexcept
  • 基类析构要 virtual；重写用 override
  • 热路径：unique_ptr 优先，shared_ptr 慎用
  • vector 必 reserve；禁止边遍历边删
  • 短临界区自旋，长 IO 用 mutex
  • 热路径不用异常，用错误码
  • 防伪共享：关键结构按缓存行对齐隔离

必背 5 · Linux / 网络口诀

  • 多线程单进程：撮合串行，网络并行
  • mmap：WAL / 共享内存投递
  • epoll ET：读到 EAGAIN；多 Reactor 网关
  • TCP_NODELAY；长度头解决粘包
  • gdb / perf / strace / free 会用会讲

必背 6 · 业务状态机

已报 → 部成/已成 → 已撤/废单

  • 买：冻资金 → 成交扣资金加持仓
  • 卖：冻股份 → 成交减股份加资金
  • T+1：可卖持仓 ≠ 当日买入
  • 盘中内存实时；日终落库 + 中证登清算

必背 7 · 限价买单口述骨架

  1. 网关校验
  2. 核验资金与涨跌停
  3. 冻结并建委托
  4. WAL 后回已报
  5. 撮合更新资券与状态
  6. 回报校验；异常靠快照+WAL；日终归档

突击顺序

全内存三问 → 内存/并发口诀 → epoll/TCP_NODELAY → 状态机与买卖冻结 → 限价买单流程。
