对照 JD 的 Checklist

按必会 / 应会 / 加分整理，面试前可逐条自检。

必会

  • 熟悉 C/C++ 语言开发，能讲清内存生命周期与常见坑
  • 熟悉常用 Linux 命令，能做基础服务端排障
  • 了解 gdb：断点、栈、多线程、core 分析
  • 了解多线程 / 多进程编程与基本同步手段
  • 了解内存管理：RAII、泄漏排查、热路径分配意识

应会

  • 数据库基础：事务 ACID、隔离级别直觉
  • 索引使用与写多读少场景下的取舍
  • 系统分析与模块方案表达能力
  • 愿意钻研经纪业务，能把规则落成设计与用例
  • 沟通协作、责任心、抗压与线上问题闭环

加分

  • Linux 服务端开发经验（守护、连接、优雅退出、监控）
  • 系统性能调优经验（profiling、尾延迟、锁与拷贝）
  • 证券业务开发经验：股债基买卖、大宗交易等

推荐复习路径

建议按顺序过一遍，每天一个模块，最后用练习模式随机抽题。

  1. Day 1 · 先读知识直讲 全内存交易、委托状态机、内存 RAII、Linux/gdb。每篇展开看「图解步骤 / 详细思路 / 易踩坑」。
  2. Day 2 · 并发 + 数据库知识直讲 把锁与不变量、事务与幂等学透，再回头刷对应面试口述题。
  3. Day 3 · 业务与性能 经纪业务主链路、性能调优方法论；能自己画出时序图和指标闭环。
  4. Day 4 · 模块设计表达 按「背景→用例→状态→失败→验证」模板，练 1～2 个模块口述。
  5. Day 5 · 面试题随机练 用恒生轨道练习模式抽题，把“会了”变成“讲得清楚”。
